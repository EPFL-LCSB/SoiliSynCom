# DiMEs and niche overlap

We provide the scripts used for DiMEs enumeration, conditioned-environment
analysis, summary generation, and niche-overlap calculations. The workflows
use MATLAB, matTFA, ReMIND, COBRA Toolbox, and a compatible MILP solver.

We provide the associated compound annotations, uptake and secretion matrices,
DiMEs summaries, and NOI matrices in the [`DiMEs data`](../../../data/graphing/DiMEs/)
and [`supplementary source data`](../../../data/supplementary/source_data/).
The conditioned-environment pools, exchange definitions, and growth-rate
constraints are under
[`data/workflow_inputs/analyses/dimes/`](../../../data/workflow_inputs/analyses/dimes/).
