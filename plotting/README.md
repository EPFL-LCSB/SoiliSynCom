# Plotting code

`main/` contains cleaned copies of all 15 manuscript plotting notebooks. Saved
execution outputs and workstation paths were removed while preserving code and
Markdown cells.

`supplementary/` contains the plotters underlying the current Supplementary V5
assets. `figure_map.tsv` records the V5 panel names. Included graphing inputs
are addressed through `tables/`; intentionally unpublished heavy inputs are
looked up below the ignored `external_data/` directory. Plotters write new
files below the ignored `outputs/` directory and never overwrite the canonical
publication figures.

These are lightly cleaned research scripts, not a turnkey end-to-end figure
reproduction system. The canonical PDFs include final manual artwork assembly.
