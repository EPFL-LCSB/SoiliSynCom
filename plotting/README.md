# Plotting code

We provide the manuscript plotting notebooks in `main/` and the current
supplementary figure scripts in `supplementary/`.

- `main/` contains 15 notebooks covering growth data, model statistics,
  curation, iMM, DiMEs, niche overlap, experimental validation, NIS, and gene
  essentiality.
- `supplementary/` contains the Python scripts used to assemble the
  Supplementary V5 panels.
- `supplementary/figure_map.tsv` links the supplementary scripts and panel
  identifiers.

Our plotting code reads study inputs from [`data/`](../data/) and writes
generated figures under `outputs/`. We provide the publication artwork under
[`figures/`](../figures/).
