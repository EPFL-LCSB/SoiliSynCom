# Tables and source data

`graphing/` retains every scientific spreadsheet, delimited table, ODS file,
and tree input from the unaltered `Code/Graphing` collection. Spreadsheet
origin-path metadata was removed from publication copies; worksheet values,
formulas, and scientific content were not changed.

`supplementary/` contains the source tables supporting the current
Supplementary V5 panels and Supplementary Table S1, plus the retained
gap-filling audit workbook. Build-only provenance indices and QA page renders
are intentionally excluded.
