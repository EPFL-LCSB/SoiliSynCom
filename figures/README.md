# Figures

We provide the publication figures in three collections:

- `main/` contains the eight manuscript figure PDFs and PNG previews.
- `supplementary/` contains all 31 Supplementary V5 sheets in PDF, SVG, and
  PNG.
- `additional/` contains the scientific graphs and editable artwork associated
  with our analyses.

We organize the corresponding figure source data under [`data/`](../data/) and
the plotting notebooks and scripts under [`plotting/`](../plotting/).
